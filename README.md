# 🚀 Proyectos Web - 5to Año

¡Bienvenidos al repositorio de proyectos de Desarrollo Web! 

## 📂 ¿Cómo empezar a trabajar?

Para mantener el orden y que todos puedan trabajar en este mismo repositorio, vamos a seguir estos pasos:

1. **Clona este repositorio** en tu computadora.
2. **Crea una nueva rama** con tu nombre. ¡No trabajes en la rama `main`!
   ```bash
   git checkout -b juan_perez
   ```
3. **Copia la carpeta `plantilla`** y pégala en la raíz del proyecto, renombrándola con tu nombre y apellido (por ejemplo: `juan_perez`).
4. **Trabaja siempre dentro de tu propia carpeta**. No modifiques la carpeta `plantilla` ni los archivos de tus compañeros.

---

## 🚀 ¿Cómo subir tus cambios a la profesora?

Cuando hayas terminado o quieras guardar tu avance, deberás subir tu rama al repositorio:

1. Agrega tus cambios:
   ```bash
   git add .
   ```
2. Crea un commit con un mensaje descriptivo:
   ```bash
   git commit -m "Agregando mi proyecto base"
   ```
3. Sube tu rama al repositorio:
   ```bash
   git push origin juan_perez
   ```
4. En GitHub, crea un **Pull Request** para que la profesora pueda revisar tu código.

---

## 🛠️ Estructura de tu carpeta

Una vez que copies la `plantilla`, tendrás esta estructura base para empezar tu proyecto:

- `index.html`: La estructura principal de tu página web.
- `css/style.css`: Aquí escribirás todos tus estilos para que la página se vea increíble.
- `js/main.js`: Aquí agregarás la interactividad y lógica de tu proyecto.
- `assets/img/`: Guarda aquí todas las imágenes, íconos y recursos visuales que uses.

> **Nota importante:** Si en el futuro necesitas instalar dependencias, recuerda que está **PROHIBIDO USAR NPM, USA PNPM**.

¡Éxitos con sus proyectos! 💻✨
